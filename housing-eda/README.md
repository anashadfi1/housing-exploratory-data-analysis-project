<h2> Section 1 : The linear Regression part </h2>
<p>The liear regression is primarily  used to model the relationship between a dependent variable and one or more independent variables. Its main goal is to predict or explain how the dependent variable changes when the independent variables change. </p> <br/>  
<p> In our script, we used this Linear Regression Algorithm to predict the Price of a house based on other properties :  ['Avg. Area Income', 'Avg. Area House Age', 'Avg. Area Number of Rooms',
       'Avg. Area Number of Bedrooms', 'Area Population'] </p>
