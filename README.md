# Housing Dataset Exploratory Data Analysis

## Project Overview

This project presents an **Exploratory Data Analysis (EDA)** conducted on a housing dataset.  
The objective is to analyze the relationships between different housing features and to build a **Linear Regression model** capable of predicting house prices based on selected variables.

Exploratory data analysis is an essential step in the data science workflow, as it helps identify patterns, correlations, and insights within the dataset before applying predictive models.

---

## Linear Regression Model

Linear Regression is a statistical method used to model the relationship between a **dependent variable** and one or more **independent variables**.  
Its primary objective is to predict the value of the dependent variable based on the observed values of the independent variables.

In this project, Linear Regression is used to **predict house prices** using the following features:

- Avg. Area Income  
- Avg. Area House Age  
- Avg. Area Number of Rooms  
- Avg. Area Number of Bedrooms  
- Area Population  

### Linear Regression Mathematical Equation

$$
y = \beta_0 + \beta_1 x
$$

Where:

- **y** represents the predicted value  
- **β₀** represents the intercept  
- **β₁** represents the coefficient associated with the independent variable  
- **x** represents the input feature
